# 右键菜单管理器 · Right-Click Menu Manager

**一个图形化工具，用来管理 Windows 11 的右键菜单——恢复 Win10 经典样式，并逐条开启、隐藏或删除菜单项。**

不用记注册表路径，不用手敲命令。勾选、点按、重启资源管理器，完事。

## 它解决什么问题

Windows 11 从 21H2 起换了精简右键菜单，把 7-Zip、Git、网盘、IDE 这些扩展全塞进「显示更多选项」的二级菜单里。想删掉某个没用的菜单项、或者把经典菜单改回来，官方没有提供界面，只能自己翻注册表。

更麻烦的是：**2026 年 10 月的更新让流传五年的注册表老方法失效了。** KB5127936 重写了右键菜单引擎，KB5132061（Build 26300.9974 / 26200.9974 / 26100.9974）之后，只在 `{86ca1aa0}` 一个 CLSID 下写空值已经不够用了，必须同时屏蔽 `{51668040}`。网上绝大多数教程还停在单键时代，照着做必然失败。

这个工具把这些都封装好了，并且**每个操作都能看到自己改的是哪一行注册表**。

## 功能

### 1. 经典菜单开关

顶部一键切换：Win10 经典右键菜单 ⇄ Windows 11 新菜单。自动处理 26H2 需要的两个 CLSID 键，并会识别「只写了一个键」这种半失效状态，直接提示「配置不完整（缺键，无效）」。

改完点「重启资源管理器」立即生效。

### 2. 逐条管理菜单项

按五个位置分类列出所有项目，每一项都显示友好名称、注册表键名、类型、所在配置单元和实际指向的 DLL/exe：

| 位置 | 说明 |
|---|---|
| 文件 | 对任意文件右键时的菜单项 |
| 文件夹 | 对文件夹右键时 |
| 文件夹空白处 | 打开文件夹后，在空白区域右键时 |
| 桌面 | 在桌面空白处右键时 |
| 驱动器 | 对磁盘、U 盘右键时 |

鼠标放在位置标签上会显示对应的注册表路径（可在设置里关掉）。

### 3. 两种处理方式

你可以在设置里指定「禁用」按钮的行为：

| 方式 | 做法 | 适用场景 |
|---|---|---|
| **标记隐藏**（默认） | 添加 `Blocked` 值 | 临时关掉，随时可撤销，数据不丢 |
| **备份后删除** | 导出 `.reg` 备份后移除整个键 | 确定不要了，清理干净 |

删除前会自动把整个键（含子键）导出到 `%APPDATA%\CtxMenuManager\backup\`，文件名带时间戳，出问题导回去即可。

### 4. 新建菜单项

填位置、键名、显示文字、命令，直接写入 `shell\<键名>\command`。比如给所有文件加一条「用 VS Code 打开」。

### 5. 界面

- 六套配色主题：午夜蓝、石墨灰、暗紫、墨绿、暖橙、日光白
- 搜索、只看已启用、隐藏系统项
- 设置项保存在本机，下次打开自动沿用

## 使用

1. 打开程序，顶部显示当前经典菜单状态
2. 想恢复 Win10 右键 → 点「开启」，再点「重启资源管理器」
3. 想清理某个菜单项 → 切到对应位置标签，找到它，点「禁用」或「删除」
4. 改完点「重启资源管理器」让文件资源管理器重新加载

**注意**：重启资源管理器会关闭所有已打开的文件夹窗口，正在运行的程序不受影响。

| 架构 | x64 |

| 权限 | **不需要管理员权限**，只写入当前用户注册表（HKCU） |

> Windows 10 及更早版本用不上这个工具——那边的右键菜单本来就是经典的。

## 安全说明

**只改 HKCU。** 所有写入都在 `HKEY_CURRENT_USER\Software\Classes` 下，不碰 `HKEY_LOCAL_MACHINE`，不影响这台机器上的其他账户，也不需要提权。

**系统项有保护。** 指向 `System32` / `SysWOW64` 的项标记为「系统」，删除按钮禁用，避免误删 Windows 自带功能。

**删除有备份。** 每次删除前导出完整 `.reg`，路径在确认框里会显示。

**但请仍然谨慎。** 注册表操作本身有风险。如果你不确定某项是干什么的，先用「标记隐藏」试试——它随时可以撤销。不确定就不要删。

## 从源码构建

```powershell
# 需要 Rust 1.77+、Node.js 18+、Visual Studio Build Tools
git clone https://github.com/TongenShen/ctx-menu-manager.git
cd ctx-menu-manager
npm install
npm run build
```

产物在 `src-tauri/target/release/bundle/`。

开发调试：

```powershell
npm run dev
```

> 在 MSYS2 / Git Bash 里跑 `npx tauri dev` 会报 `Cannot find native binding`，因为 Tauri CLI 只有 msvc 绑定。请用 PowerShell 或 cmd。

## 常见问题

**开了经典菜单但没反应？**
先重启资源管理器。还不行的，检查是不是只写了一个 CLSID——设置面板的状态会显示「配置不完整」。程序会自动补上第二个键。

**以前改过注册表，现在失效了？**
2026 年 10 月之后的更新让单键方案失效了。用本工具重新开启一次即可，它会写两个键。

**删除后想恢复？**
去 `%APPDATA%\CtxMenuManager\backup\` 找对应时间戳的 `.reg` 文件，双击导入。或者直接用「标记隐藏」模式，根本不需要恢复。

**需要管理员权限吗？**
不需要。所有操作都在当前用户范围内。只有你手动选择写入 HKLM 时才需要提权，程序会标注出来。
